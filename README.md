
# StudentRoadmap 

## 📱 About the Project

**StudentRoadmap** is a comprehensive career guidance Android application designed to help Indian students navigate their career paths after 10th, 12th, or diploma. The app provides personalized roadmaps, career assessments, and expert-curated resources to help students make informed decisions about their future.

---

## 🎯 The Idea

Choosing a career path in India is overwhelming — students face pressure from family, society, and a lack of reliable information. Most existing resources are scattered, outdated, or too generic.

**StudentRoadmap solves this** by offering a single, trustworthy platform where students can:

- **Discover** careers that match their personality and skills
- **Explore** step-by-step roadmaps for 50+ career paths (Doctor, Engineer, CA, Civil Servant, Designer, and more)
- **Track** their progress as they complete each milestone
- **Download** personalized roadmap PDFs to share with parents and mentors
- **Get clarity** on fees, top colleges, required skills, and entrance exams

The app was built by diploma students, for students — with real experiences and practical insights baked into every feature.

---

## ✨ Core Features

| Feature | Description |
|---------|-------------|
| 🧭 **Career Quiz** | AI-powered assessment that suggests careers based on interests and strengths |
| 🗺️ **Interactive Roadmaps** | Step-by-step guides with progress tracking for each career |
| 📊 **Progress Tracker** | Visual journey tracker with motivational milestones |
| 📄 **PDF Export** | Download and share career roadmaps as professional PDFs |
| 🎓 **Career Database** | 50+ careers across Healthcare, Engineering, Commerce, Arts & Government |
| 📚 **College & Fee Info** | Verified data on top institutions and average course fees |
| 🎨 **Modern UI** | Clean, animated, mobile-first design with bottom navigation |

---

## 🛠️ Tech Stack

- **Language:** Java
- **UI:** XML Layouts + Material Design Components
- **Architecture:** Activity-based with RecyclerView & ViewPager2
- **Storage:** SharedPreferences for progress persistence
- **Libraries:** CardView, BottomSheetDialog, ViewPager2, ConstraintLayout
- **PDF Generation:** Android Print Framework + WebView
